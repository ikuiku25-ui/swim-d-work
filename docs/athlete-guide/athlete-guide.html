SWIM D-work

選手向け 使い方ガイド

このアプリでできること
  • ドライランド・水中練習・試合の予定を、自分で入れる
  • コーチが入れたドライランドのメニューを見る
  • メニューを見ながら実施して、やった種目をチェックする
  • メニューが入ったら、スマホに通知が届く

アプリの URL：https://swim-d-work.pages.dev

もくじ
  1. はじめての準備（最初の1回だけ）
  2. 予定を入れる
  3. 予定を変える・中止する・コピーする
  4. メニューを見て、実施を記録する
  5. 通知について
  6. 困ったときは

1. はじめての準備（最初の1回だけ）

コーチに招待されると「SWIM D-work ログインコード」というメールが届きます。iPhone で次の順番に進めてください。

1ホーム画面に追加する

  1. iPhone の Safari で https://swim-d-work.pages.dev を開く
  2. 画面の下にある共有ボタン（四角から上向きの矢印）を押す
  3. ホーム画面に追加 → 追加
  4. ホーム画面にできた 「D-work」のアイコンから開く
通知を受け取るには、必ずホーム画面のアイコンから開いてください。Safari のままでは通知が届きません（iOS 16.4 以上が必要です）。

2メールアドレスを入れる

  • コーチに伝えたメールアドレスを入れて ログイン用のコードを送る
  • パスワードはありません
「登録されていないメールアドレスです」と出たら、コーチに招待してもらったアドレスか確認してください。

3メールのコードを入れる

  • メールに届いた6桁の数字を入れて ログイン
  • コードの有効期限は1時間。切れたら コードを再送する
  • 一度ログインすれば、次からは開くだけで使えます

4通知を有効にする

  • ログインすると「通知を受け取る準備をしましょう」が出ます
  • 通知を有効にする → 出てきた確認で 許可
  • あとからでも、右上の 設定 からできます
設定画面の テスト通知を送る で、通知が届くか確かめられます。

2. 予定を入れる

コーチは、あなたが入れた「ドライランド」の予定にメニューを入れます。ドライランドをする日時が決まったら、早めに入れてください。

1カレンダー（週表示）

  • アプリを開くと、今日から7日間が表示されます
  • 左右にスワイプすると、前後の7日に移動します
  • 上の 月 で1か月の表示に切り替わります
  • 色：● ドライランド　● 水中練習　● 試合
印意味
メニュー未設定コーチのメニューがまだ入っていない
メニューありメニューが入った。開いて確認しよう
実施中記録を途中まで入れた
実施済み完了にした
中止中止にした予定

2予定を追加する

  1. その日の ＋ 追加 を押す
  2. 種類（ドライランド／水中練習／試合）を選ぶ
  3. 日付・開始時刻・場所・時間（分）を入れる。時間は「30分」「40分」などのボタンでも選べます
  4. いちばん下のボタンで追加
1日に何件でも入れられます。朝練と放課後のドライランド、のように分けて入れてください。

3. 予定を変える・中止する・コピーする

カレンダーの予定を押すと、編集画面が開きます。

1同じ予定を何日分も入れる（コピー）

  1. 予定を開いて コピーして他の日に貼り付ける
  2. 月表示になるので、入れたい日をタップして選ぶ（何日でも選べます）
  3. 貼り付け（○日） を押す
  • コピーされるのは、種類・時刻・場所・時間だけです（メニューはコピーされません）
  • その日の予定は消えずに、追加されます

2変更する・中止する・削除する

  • 変更：日付や時刻を直して 変更を保存。メニューが入っている予定を変えると、コーチに知らせが届きます
  • 中止：中止にする → 理由をひとこと入れる（例：発熱、テスト期間）。中止は 中止を取り消す で元に戻せます
  • 削除：削除する。間違えて入れた予定に使います
コーチのメニューが入った予定は削除できません。行けなくなったら「中止」にしてください。種類（ドライランドなど）も変えられません。

4. メニューを見て、実施を記録する

コーチがメニューを入れると通知が届き、カレンダーの予定に メニューあり が付きます。

1メニューを見る

  • 予定を開くと「コーチからのメニュー」が表示されます
  • 単独：1つの種目を決められたセット数行う
  • サーキット：いくつかの種目を順番に行い、それを決められた周回数くり返す
  • 実施するときは メニューを実施する（記録）

2やった種目にチェックする

  • やった種目の □ にチェックを入れる
  • 回数・秒数・負荷は、最初から計画の値が入っています。計画と違ったときだけ数字を書き換えてください（書き換えた欄は黄色になります）
  • セット数や周回数が計画と違ったら、「実施セット数」「実施周回数」を直す（例：3周の予定 → 2周）
  • 入力は自動で保存されます（画面の下に「保存しました」）
途中でアプリを閉じても大丈夫。次に開くと続きから入れられます。

3メニューにない種目を足す・完了にする

  • メニューにない種目もやったときは、いちばん下の「追加分」の ＋ 種目を追加 で入れる
  • 終わったら 完了（実施済みにする）。カレンダーに 実施済み が付きます
  • 全部の種目にチェックが付いていなくても完了にできます。完了したあとでも直せます
記録を始めると、コーチはそのメニューを変更できなくなります。メニューに変更してほしいところがあれば、記録を始める前にコーチに伝えてください。

5. 通知について

1届く通知

通知届くとき
「11/10（火）のドライランドにメニューが入りました」コーチがメニューを入れて通知したとき
「11/10（火）のメニューが変更されました」コーチがメニューを直して通知したとき
「11/10（火）ほか2日のメニューが入りました」何日分かまとめて入ったとき（1通にまとまります）
  • 通知を押すと、アプリが開きます
  • 通知が来なくても、アプリを開けばメニューは見られます

2設定画面（右上の「設定」）

  • 通知を有効にする：この iPhone で通知を受け取る
  • テスト通知を送る：通知が届くか確かめる
  • この端末の通知をやめる：この iPhone では通知を受け取らない
  • ← カレンダー または左上の「SWIM D-work」でカレンダーに戻る

6. 困ったときは

ログインコードのメールが届かない
迷惑メールフォルダを確認してください。それでもなければ、少し待ってから コードを再送する を押してください。何度も続けて押すと、しばらく送れなくなります。
「コードが正しくないか、有効期限が切れています」と出る
コードの有効期限は1時間です。コードを再送する で新しいコードを受け取り、いちばん新しいメールのコードを入れてください。
通知が届かない
① ホーム画面の「D-work」から開いているか（Safari のままでは届きません）
② iPhone の「設定」→「通知」→「D-work」で「通知を許可」がオンか
③ 集中モード（おやすみモードなど）がオンになっていないか
④ アプリの「設定」→ テスト通知を送る で届くか。届かなければ 通知を有効にする を押し直す
画面が古いまま・おかしい
アプリを完全に閉じて（画面の下から上にスワイプして、D-work を上に払う）、ホーム画面から開き直してください。2回くり返すと新しい版になります。
機種変更した・別のスマホでも使いたい
新しいスマホで「1. はじめての準備」をもう一度行ってください。ログインはメールアドレスとコードだけでできます。通知は、その端末で 通知を有効にする を押し直してください。
「このアカウントは利用できません」「停止されています」と出る
コーチに確認してください。
予定を削除できない
コーチのメニューが入った予定は削除できません。「中止にする」を使ってください。

あなたが入れた予定と記録は、あなたとコーチだけが見られます。ほかの選手には見えません。
わからないことがあれば、コーチに聞いてください。
