# SWIM D-work 要件定義書

Nov 5, 2026 · @IKUMI

## 概要

アプリ名は「SWIM D-work」（D はドライランドの頭文字）。コーチ1人と競泳選手（高校生中心、5人以下）が、互いのスマホでドライランド（陸トレ）のメニューと実施記録を共有するアプリ。選手が予定を入れ、コーチがドライランド枠にメニューを入れ、選手が実施結果を記録する。

基本の流れは次のとおり。

1. 選手がカレンダーに予定を入力する（ドライランド、水中練習、試合）
2. コーチが選手のドライランド枠にメニューを入れる
3. 選手に通知が届き、メニューを見ながら実施して種目ごとにチェックする
4. コーチが計画と実績の差を確認する

| 項目 | 内容 |
| --- | --- |
| 利用者 | コーチ1人、選手5人以下（高校生中心） |
| 端末 | 各自のスマホ（iPhone 含む） |
| 閲覧範囲 | 選手は自分のデータのみ、コーチは全員分 |
| 振り返り・分析機能 | なし |

## 技術構成

PWA と Supabase で構成し、開発は Claude Code で行う。この人数なら無料枠で運用できる見込み。

| 要素 | 採用技術 | 役割 |
| --- | --- | --- |
| アプリ本体 | PWA（ホーム画面に追加して使う Web アプリ） | 選手・コーチ共通の画面。iPhone でもプッシュ通知を受信 |
| ログイン | Supabase Auth（メールのリンクでログイン） | パスワード不要 |
| データベース | Supabase（PostgreSQL） | 行単位のアクセス制御で、選手は自分のデータしか読み書きできないようにする |
| 定期処理 | Supabase の定期実行 | 毎晩22時の未設定チェック |
| 即時処理 | Supabase のデータ変更時トリガー＋関数 | 即時通知、メニュー設定時の通知 |
| 通知 | Web Push | コーチ・選手双方へのプッシュ通知 |

アクセス制御はアプリ側ではなくデータベース側で強制する。アプリに不具合があっても他人のデータが見えない構造にするため。

## 権限とアカウント

役割はコーチと選手の2種類。選手はコーチの招待がないと登録できない。

| 操作 | コーチ | 選手 |
| --- | --- | --- |
| 予定の入力・編集・中止 | 全員分を閲覧 | 自分の分のみ |
| メニューの作成・編集 | 可 | 不可（閲覧のみ） |
| 実施チェック・実績修正・種目追加 | 閲覧のみ | 自分の分のみ |
| 参考メニュー帳・テンプレート | 可 | 表示しない |
| 選手の招待・停止 | 可 | 不可 |

**登録の流れ**

1. コーチが選手管理画面で選手の名前とメールアドレスを登録する
2. 選手にログイン用リンクがメールで届く
3. 選手がリンクからログインし、ホーム画面に追加して通知を許可する

停止した選手はログインできなくなるが、過去のデータは残す。

## 予定（カレンダー）

予定は選手が1日ずつ入力し、コピーして複数日に貼り付けられる。繰り返し登録は設けない。

**予定の項目**

| 項目 | 内容 |
| --- | --- |
| 種類 | ドライランド／水中練習／試合 |
| 日付・開始時刻 | 必須 |
| 場所 | 自由入力 |
| 時間 | 分単位 |
| 状態 | 通常／中止（中止時は理由を入力） |

**表示**

- 週表示（ホーム）：今日を先頭に7日間。左右スワイプで前後7日へ移動
- 月表示：1日始まり。試合までの流れを見渡す用
- 種類ごとに色分け。ドライランド枠には「メニュー未設定／設定済み／実施済み」の印
- 1日に複数の予定を入れられる

**コピーと貼り付け**

1. 予定を開いて「コピー」を押す（週表示から押した場合は月表示に切り替わる）
2. 月表示で貼り付け先の日付を複数タップして選ぶ
3. 「貼り付け」で選んだ日すべてに追加される

コピーされるのは枠（種類・時刻・場所・時間）だけで、メニューは含まない。貼り付け先に既存の予定があっても上書きせず追加する。

**変更と中止**

- 日付・時刻・場所・時間を変更しても、入っているメニューと実施記録は枠ごと引き継ぐ
- 変更された枠は、コーチ側に「変更あり（11/10 → 11/12）」のように表示する
- メニューが入っていない枠は自由に削除できる
- メニューが入っている枠は削除できず「中止」にする。中止理由を一言入力し、記録は残す

## メニュー構造

1回分のメニューは、ブロックを上から順に並べたもの。ブロックは「単独」と「サーキット」の2種類。

| 階層 | 項目 |
| --- | --- |
| ブロック（単独） | 種目1つ、セット数、セット間休憩、メモ |
| ブロック（サーキット） | 種目の並び、周回数、種目間休憩、周回間休憩、メモ |
| 種目 | 種目名、回数または秒数、負荷（自重、ダンベル○kg など）、メモ |

**例**

1. ウォームアップ（単独）：ジョグ 1セット × 5分
2. サーキット 3周（種目間15秒、周回間90秒）：スクワット 15回、プッシュアップ 10回、プランク 30秒
3. 単独：懸垂 3セット × 8回（休憩60秒）
4. クールダウン（単独）：ストレッチ 10分

**作成時の補助**

- 種目名は過去に使ったものを候補表示する
- テンプレートを呼び出してメニューに入れられる
- 作ったメニューをコピーして、複数の選手・日付のドライランド枠にまとめて貼り付けられる

## 実施記録

選手は種目ごとにチェックし、違った数値だけ書き換える。計画値と実績値は別々に保存し、上書きしない。

**選手の操作**

- 各種目にチェックボックス
- 回数・秒数・負荷・セット数は計画値が入った状態で表示し、違うときだけ修正する
- サーキットはブロックに「実施周回数」を1つ持たせる（3周予定 → 2周、など）
- 選手が自分で追加した種目は、メニュー末尾の「追加分」に入る

**コーチの確認画面**

- 計画どおりの種目は通常表示
- 数値を変えた種目は「計画 15回 → 実績 12回」と差分を表示
- 未チェックの種目と追加種目は目立つ色で表示

## 参考メニュー帳とテンプレート

Web で見つけたメニューをコーチ専用の参考メニュー帳にメモし、そこから自分のテンプレートを作ってメニューに使う。選手には表示しない。

**参考メニュー帳の項目**

| 項目 | 内容 |
| --- | --- |
| タイトル | 例：肩甲骨まわりの安定化サーキット |
| 出典URL | 元ページへのリンク |
| メモ | 要点、選手に合わせて変えたい点など |
| タグ | 体幹、肩、下半身、試合前、オフ期 など。一覧で絞り込みに使う |

元ページの文章や画像は丸ごと保存せず、URL と自分の言葉の要点メモで管理する。

**テンプレート**

- メニューと同じブロック形式で作成・保存する
- 参考メニュー帳の詳細画面から「テンプレートを作る」で作成を始められる
- メニュー作成画面から呼び出し、内容を調整して使う

## 通知

通知はすべてスマホのプッシュ通知。時刻は日本時間。

| 宛先 | タイミング | 条件 | 内容の例 |
| --- | --- | --- | --- |
| コーチ | 毎晩22:00 | 翌日のドライランド枠にメニュー未設定がある（なければ送らない） | 明日メニュー未設定：Aさん 16:00 学校 40分／Bさん 18:30 自宅 30分 |
| コーチ | 即時 | 22:00以降に翌日のドライランド枠が追加・移動された | Aさん 明日 7:00 自宅 30分 が追加されました（メニュー未設定） |
| コーチ | 即時 | 当日になってから当日のドライランド枠が追加・移動された | 同上 |
| コーチ | 即時 | 選手がドライランド枠を変更・中止した | Aさん 11/10 のドライランドが中止されました（理由：発熱） |
| 選手 | 即時 | コーチがメニューを入れた | 11/10（火）のドライランドにメニューが入りました |
| 選手 | 即時 | コーチがメニューを変更した | 11/10（火）のメニューが変更されました |

- 水中練習と試合の枠は通知の対象外
- コーチが複数日分のメニューをまとめて貼り付けた場合、選手への通知は1通にまとめる
- 通知を受けるには、ホーム画面への追加と通知の許可が必要（初回ログイン時に案内する）

## 画面一覧

選手側4画面、コーチ側7画面。ログイン画面は共通。

| 利用者 | 画面 | 主な内容 |
| --- | --- | --- |
| 共通 | ログイン | メールアドレス入力、ログインリンク送信 |
| 選手 | カレンダー（ホーム） | 週表示（今日から7日）と月表示（1日始まり）。種類別の色分け、メニュー状態の印 |
| 選手 | 予定の入力・編集 | 種類、日付、時刻、場所、時間。コピー、中止（理由入力）、削除（メニューなしの場合のみ） |
| 選手 | メニュー実施 | ブロックごとの種目表示、チェック、実績修正、実施周回数、種目の追加 |
| コーチ | 全員カレンダー（ホーム） | 全選手の予定を選手別に色分け、選手で絞り込み。未設定・変更あり・中止を強調 |
| コーチ | メニュー作成・編集 | ブロックの組み立て、テンプレート呼び出し、他の選手・日付へのコピー貼り付け |
| コーチ | 実施結果の確認 | 計画と実績の差分、未チェック、追加種目の強調表示 |
| コーチ | テンプレート一覧 | 作成、編集、削除 |
| コーチ | 参考メニュー帳 | 一覧（タグで絞り込み）、詳細、「テンプレートを作る」 |
| コーチ | 選手管理 | 選手の招待（名前・メール）、停止 |
| コーチ | 設定 | 通知の許可 |

## 対象外と未決事項

**今回は作らないもの**

- 振り返り・分析機能（期間別の実施率、種目別の推移など）
- 予定の繰り返し登録
- 複数コーチ対応
- セット・周回ごとの細かいチェック
- 種目の動画リンク、きつさ（RPE）の記録
- アプリストアでの配信

**未決事項**

なし（すべて決定済み）。
